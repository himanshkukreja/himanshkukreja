## 🔥 Featured Projects

### 📱 iOS Bridge

🔗 https://github.com/himanshkukreja/ios-bridge  
[![GitHub stars](https://img.shields.io/github/stars/himanshkukreja/ios-bridge?style=flat-square)](https://github.com/himanshkukreja/ios-bridge/stargazers)

Complete iOS Simulator remote control platform built for distributed teams that need to stream, control, and automate simulators from anywhere.

- Real-time simulator streaming with touch interaction
- App lifecycle management and recording workflows
- Built for remote QA, automation, and mobile engineering teams

### 🔗 BridgeLink

🔗 https://github.com/himanshkukreja/bridgelink

Production-ready CLI for exposing local Android devices remotely without adding friction to the developer workflow.

- Secure tunneling via `bore`
- Clean integration with NativeBridge
- Designed for remote device access and testing flows

### 🧠 CodeFlow Analyzer

🔗 https://www.npmjs.com/package/codeflow-analyzer

Static analysis tooling for React and Next.js codebases that helps engineers understand behavior without running the app.

- No runtime execution required
- Generates behavioral reports for large frontends
- Useful for onboarding, architecture discovery, and code audits

### ✍️ Markdrop

Minimal anonymous markdown publishing with a sharp focus on speed and simplicity.

- No login required
- Instant shareable links
- Peer-to-peer transfer via WebRTC
